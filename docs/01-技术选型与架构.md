# TeleOps 技术选型与架构

> 版本：v0.8.22 · 整理时间：2026-09-06
> 本文回答「用到了哪些技术」与「整体怎么搭」。部署流程见 `02-搭建与部署流程.md`，难点与踩坑见 `03-核心难点与踩坑记录.md`。
> 功能层面的完整盘点另见仓库根目录 `TeleOps_项目梳理.md`。

---

## 1. 一句话定位

**Agent 平台底座 + 两个智能体（研发数字员工 / 运维 Agent）的纵向闭环**，对应运营商「业务运维一体化」叙事。整套东西**零依赖离线可演示、可自托管上公网、数据真实可信**。

---

## 2. 技术栈全景

| 层 | 技术 | 用途 | 选型理由 |
|---|---|---|---|
| 语言 | **Python 3.11 / 3.13** | 后端、Agent、脚本 | 算子/算子库生态成熟；本机用 WorkBuddy 隔离 Python，无需自建 venv |
| Web 框架 | **FastAPI** + **Uvicorn** | REST API + 同源托管静态前端 | 异步、自带 Swagger `/docs`、单端口同时出 API 和界面 |
| Agent 编排 | **LangGraph 0.2.76**（锁定 `<0.3`） | 有状态工作流（运维图 / 研发图） | 显式状态机契合「降噪→根因→调工具→造工具」多步流程；1.x API 不兼容，必须锁版本 |
| LLM | **DeepSeek**（OpenAI 兼容接口） | 真实推理；无 Key 自动降级 Mock | 国产模型叙事；`LLMClient` 抽象层可换 Qwen/GLM 只改 `config.py` |
| LLM SDK | **openai>=1.0** | 调 DeepSeek（兼容协议） | 免写自定义客户端 |
| 向量检索 | **ChromaDB**（可选）+ 字符级兜底 | 知识库 RAG | 有 Chroma 走向量，无则字符级重叠打分兜底，**中文无空格分词也不崩** |
| 图拓扑 | **networkx**（可选）+ 内置轻量兜底 | CMDB 依赖图 | 同样「有则用之、无则兜底」，保证任意机可跑 |
| 持久化 | **SQLite** | 工具库/Workspace/Agent/审计/用户 | 零运维、单文件、事务可靠；工具注册表为「活视图」即时可见 |
| 鉴权 | **JWT**（自研，`python-dotenv` 取密钥） | 登录态 + 多租户归属 | 无外部依赖；登出进黑名单（`jti` 维度） |
| 限流 | **自研滑动窗口**（`src/core/rate_limit.py`，零依赖） | 防爆破/滥用 | 不引 slowapi，读写登录分档，失败返回 429 + `Retry-After` |
| 反向代理 / HTTPS | **Caddy 2**（`tls internal` 自签 / Let's Encrypt 公网） | 443 反代 8000、证书自动续期 | 配置即代码、自动 HTTPS，省去手动证书 |
| 容器化 | **Docker / Compose** | 自托管编排（backend + caddy + 可选 Prometheus/Grafana） | 进程守护 + 密钥不入库 + 业务卷持久化 |
| 前端 | **原生 JS + HTML + CSS**（`web/`） | 8 视图操作台 | 不引框架，单文件易读、零构建、FastAPI 静态托管即可 |
| 截图工具 | **Playwright**（dev-only） | 文档配图抓取 | 仅 `npm run shots` 用，不进运行时依赖 |
| 测试 | **pytest** | 134 项接口/鉴权/闭环/隔离/限流回归 | 免启服务、全绿即通过，CI 友好 |

> 关键约束：**任何一层都「可替换 + 有兜底」**——模型换 `config.py`、向量库换 Chroma/字符级、图库换 networkx/内置、前端换 Gradio/API。这正是「平台底座」的设计意图。

## 3. 五层架构

```
┌──────────────────────────────────────────────────────────────┐
│  前台 / 服务层                                                 │
│   web/ (8 视图, FastAPI 同源托管)   ·  app.py (Gradio 备选)     │
│   Caddy(443) ──反代──▶ FastAPI(8000)                          │
├──────────────────────────────────────────────────────────────┤
│  服务层  src/api/server.py (FastAPI：/auth /workspaces /alert …)│
├──────────────────────────────────────────────────────────────┤
│  编排层  src/orchestration/graphs.py (LangGraph 工作流)        │
├──────────────────────────────────────────────────────────────┤
│  Agent 层                                                     │
│   src/agents/ops_agent.py  (降噪/根因/调工具/处置)             │
│   src/agents/dev_agent.py  (CodeGen造工具/注册/变更单/SOP)     │
├──────────────────────────────────────────────────────────────┤
│  能力层  src/core/                                            │
│   cmdb_graph.py (拓扑) · tool_registry.py (工具库)             │
│   kb_store.py (知识库 RAG) · llm_client.py (LLM 抽象层)        │
│   auth.py(鉴权) · workspace_store.py(多租户) · db.py(持久化)   │
│   alert_stream.py(告警流) · rate_limit.py(限流) · usage/metrics│
├──────────────────────────────────────────────────────────────┤
│  接入层  src/adapters/  (Zabbix/ELK… 配置驱动 + demo 兜底)     │
├──────────────────────────────────────────────────────────────┤
│  数据层  data/ (topology/tools/feedback=自造; alerts=公开)     │
│           kb/ (MITRE ATT&CK / SRE 公开知识)                    │
└──────────────────────────────────────────────────────────────┘
```

## 4. 模块职责速查

| 模块 | 职责 |
|---|---|
| `src/config.py` | 全局路径 + 模型配置（provider/Key/base_url），统一取路径 |
| `src/llm_client.py` | `LLMClient` 抽象层 + 离线确定性 Mock（`[TASK:xxx]` 路由）；无 Key 自动降级 |
| `src/orchestration/graphs.py` | `build_ops_graph`（normalize→diagnose）、`build_dev_graph`（codegen→register→sop） |
| `src/agents/ops_agent.py` | `handle_alert`：降噪→根因（CMDB+KB）→调工具→发现缺工具→汇总 |
| `src/agents/dev_agent.py` | `fulfill_feedback`：生成工具脚本→注册→变更单→写 SOP 进 `kb/` |
| `src/core/tool_registry.py` | SQLite **活视图**：list_tools/get 实时查库，全 Agent 即时可见；`call` 动态 import `tools/*.py`；高风险拦截返回 `blocked` |
| `src/core/cmdb_graph.py` | `CMDBGraph`：依赖/被依赖/邻居/节点信息；networkx 优先，内置图兜底 |
| `src/core/kb_store.py` | `retrieve(query,top_k)` 切片检索；Chroma 优先，字符级兜底（解决中文分词） |
| `src/core/auth.py` | JWT 签发/校验、密码哈希、**登出黑名单**（jti 维度，持久化） |
| `src/core/workspace_store.py` | 多租户：个人域 `ws-<用户>` + 公共域 `core-net`；`is_visible_to()` / `is_writable_by()` 唯一判定入口 |
| `src/core/db.py` | SQLite 连接 + 各业务表；`audit()` 静默落审计（旁路，不影响主流程） |
| `src/core/alert_stream.py` | 每业务域一条独立告警流水线 `_streams` dict；`started_by` 记录启动者 |
| `src/core/rate_limit.py` | 零依赖滑动窗口限流（登录 5 / 写 60 / 读 120 每分钟每 IP） |
| `src/adapters/` | `base.py` + `sample_adapters.py`(本地) + `real_adapters.py`(Zabbix/ELK，配置驱动+demo兜底) + `reserved_adapters.py`(占位)；`registry._register_all()` 统一注册 |
| `src/api/server.py` | 全部 REST 端点 + `/audit` + 静态托管；承载多租户/审计埋点 |
| `web/` | `index.html` + `app.js` + `styles.css`：作战室/闭环看板/消息栏/接入层/拓扑/工具库/知识库/操作审计 8 视图 |
| `scripts/` | `teleops_ctl.py`(进程管理：start/stop/restart/status/caddy/firewall/…)、`caddy_runner.py`(HTTPS 反代启停+PID 自愈)、`caddy_setup.py`(下载二进制)、`gen_data.py`/`ingest_public.py`(造数/接公开数据) |

## 5. 核心闭环（技术如何串起来）

```
告警 → OpsAgent.handle_alert
  → normalize 降噪
  → rootcause（CMDBGraph 拓扑 + KBStore 知识库 RAG）
  → run_recommended_tools（ToolRegistry.call 动态执行 tools/*.py）
  → detect_missing_tool 发现缺工具
  → 生成反馈工单 → DevAgent.fulfill_feedback
      → generate_tool 落盘 tools/xxx.py
      → register_tool 进 tools.json/SQLite（全 Agent 即时可见）
      → write_sop 沉淀 SOP 进 kb/
  → 第二轮运维复用新工具处置成功 → 闭环完成（trace 留存）
```

对外由 `server.py` 的 `/feedback`、`/closed-loop/run` 与 web 闭环看板触发；证据留在 `traces/`。

## 6. 数据策略（真实 + 自造，统一 Schema 接入）

- **真实公开**：`alerts.json` 来自 LogHub 公开日志（证明「真告警、真字段」）；`kb/` 来自 MITRE ATT&CK / SRE 公开知识（证明「真知识、可 RAG」）。
- **自造建模**：运营商真实拓扑/工具库/反馈不公开，按场景建模紧贴 JD。
- **统一接入**：两类数据经 `config.py` 统一路径 + 能力层统一读取，**能力层零改动即可切换**。

---

## 7. 可替换性设计（平台底座的体现）

| 想换什么 | 改哪里 | 兜底 |
|---|---|---|
| 大模型 | `config.py`（provider/key/base_url） | 无 Key → Mock 确定性路由 |
| 向量库 | `KBStore` 构造 | 字符级重叠打分 |
| 图库 | `CMDBGraph` 构造 | 内置轻量邻接表 |
| 前端 | 换 Gradio/app.py 或调 API | FastAPI 同源托管 |
| 外部系统（Zabbix/ELK） | `data/adapters.json` + `real_adapters.py` | demo 数据兜底，映射逻辑可单测 |
