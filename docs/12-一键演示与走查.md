# TeleOps 一键演示与走查指南（面试现场版）

> 目标：面试官当场 30 秒内看到「运维告警 RCA 作战室」完整跑起来，并能顺着一条 5G 故障
> 看到 **实时告警 → 根因假设 → 工具缺口 → 研发造工具 → 复用闭环 → 审计留痕** 的全链路。
> 配套脚本：`scripts/demo.py`（把"起后端 / 注册账号 / 进个人域 / 起 5G 实时流 / 开浏览器"收敛成一条命令）。

---

## 0. 一条命令开演

```bash
# 在项目根目录
python scripts/demo.py                 # 默认 http://127.0.0.1:8000
python scripts/demo.py --port 9000     # 端口被占用时换端口
python scripts/demo.py --no-browser    # 服务器/无界面环境
```

脚本会：
1. 检测后端是否存活，没起就后台拉起（`teleops_ctl start`，脱离父进程）；
2. 注册/登录演示账号 `interviewer` / `Interview123`（幂等，已存在则直接登录）；
3. 自动进入该账号的**个人业务域**，并启动 **5G 主题实时告警流**（快节拍 + 循环）；
4. 自动打开浏览器到作战室界面；
5. 打印账号、业务域、走查要点。

演示账号：`interviewer` ／ `Interview123`（默认角色 `sre`，拥有 `tool.exec`/`agent.manage`）。
若要演示**管理员视角**（RBAC 角色分配、HITL 审批、审批面板），请用你本机已有的管理员账号登录。

## 1. 两分钟电梯演讲（面试开场直接背）

> TeleOps 是给**百人规模电信运营商内部**做的「**运维告警 RCA 作战室**」——不是又一个 dashboard，
> 而是一个**多 Agent 协作的告警处置闭环**。
>
> 它把一条告警接进来后，由**运维 Agent** 做降噪 + 根因假设 + 工具探测；当发现现有工具库
> 缺能力时，自动派发**研发 Agent** 现场造工具并回流复用——**缺工具 → 造 → 复用** 的演化史
> 是系统自己长出来的。整个处置过程**全程审计留痕、可回放、可导出处**，并接了
> **HITL 人工审批**作为高风险动作的闸。
>
> 工程上它已经具备**多租户硬隔离**（百人互不串域）、**RBAC 角色分化**、**SSO/OIDC**、
> **限流/HTTPS/防火墙**、可切 **Postgres + 多 worker + Caddy 多后端 + Redis 外置** 的水平扩容，
> 以及**生产部署清单**与**合规/数据主权方案**文档。模型层做了**配置驱动 + mock 兜底**，
> 所以**没有外网/没有 Key 也能现场完整演示**。

## 2. 现场点击路径（按这个顺序点，故事最顺）

| 步骤 | 在哪看 | 讲什么 |
|---|---|---|
| ① 登录 | 作战室首页 | 演示账号 `interviewer` 登录，默认落进**个人业务域**（多租户隔离，看不到别人的域） |
| ② 实时告警流 | 右侧常驻「实时告警流」面板 | 5G 告警持续滚动：gNodeB 前传光功率劣化 / BBU 过热 / 承载端口错包 / AMF 过载 / UPF 掉线，**噪声里揪真故障** |
| ③ 根因假设 | 点开一条告警卡片 | 运维 Agent 给出**多层根因假设**（置信度排序），调用 `pull_metrics`/`pull_logs` 取证 |
| ④ 工具缺口→造工具 | 同卡片「工具探测」区 | 遇到库内缺的能力（如光功率探针）→ **自动登记需求并派发研发 Agent** → 现场生成工具脚本 |
| ⑤ 复用闭环 | 第二轮同类故障 | 工具已由第一轮沉淀，**直接复用**，把"沉淀→复用"演化史演示出来 |
| ⑥ 审计回放 | 顶部「审计」页 | 全部操作（告警接入/造工具/审批）**留痕 + 时间轴回放 + CSV/JSON 导出 + OSS 归档** |
| ⑦ 权限与审批 | 「设置」页 | HITL 开关、RBAC 角色（viewer/dev/sre/org_admin/super_admin）、管理员审批面板 |
| ⑧ 工程化谈资 | 指文档 | 提 `docs/10` 生产部署清单（百人容量评估/限流反代坑）、`docs/11` 合规与数据主权（等保/模型私有化）即可，不必现场翻 |

## 3. 无网 / 无 Key 降级（关键兜底）

- 系统 LLM 默认**配置驱动 + mock 兜底**：没有 `DEEPSEEK_API_KEY` 或断网时，自动降级 mock 模式，
  RCA 根因与工具建议**仍完整产出**，演示不依赖外网。
- 若想现场展示**真实推理**：在 `.env` 配置 `DEEPSEEK_API_KEY` 后重启即可（注意合规红线——
  真实模型私有化/数据不出域见 `docs/11`，正式接入真实告警前需先满足）。

## 4. 边界与故障兜底

- **端口被占用**：用 `python scripts/demo.py --port 9000`，并先 `python scripts/teleops_ctl.py start --port 9000`。
- **人工审批闸开启**：若 `require_approval` 为开，告警流会进入 `pending_approval`，演示前请在「设置」关闭，
  或 `set TELEOPS_REQUIRE_APPROVAL=0` 后重启。
- **注册开启邀请码**：若服务端设了 `TELEOPS_INVITE_CODE`，运行前 `set TELEOPS_INVITE_CODE=你的邀请码`。
- **想重置演示数据**：`python scripts/reset_demo.py`（工具库回到内置两件套，可重跑"造工具"闭环）。
- **已知测试 flake**：`tests/test_oss_export.py` 在共享 session DB 全量跑时偶发 `sqlite3.OperationalError`，
  隔离跑全绿，与产品逻辑无关（套件共享-DB 争用），不影响演示与功能。
