接入层 · 外部系统适配器

TeleOps 不直接替换现有运维系统，而是通过「适配器」把外部数据（告警/日志/CMDB/工单/知识）接进内核统一 Schema，并把 Agent 的决策经执行适配器下发到设备。以下接口已设计预留，样板可真实运行。

🧪 告警接入测试（Prometheus 样板）

点「发送样例告警」会把一段 Alertmanager 标准 webhook 经 alert-prometheus 适配器解析为统一告警，并直接喂给运维 Agent 做根因分析。

  "alerts": [{
    "labels": {"alertname": "HostHighTemp", "instance": "host-1:9100",

    "startsAt": "2026-09-01T10:00:00Z"
  }]
}
